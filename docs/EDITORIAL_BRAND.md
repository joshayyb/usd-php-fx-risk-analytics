# Editorial identity

Use the article's question as the headline. Open with an observed case, give its scope in the deck, and let the reader reach the evidence in one click. Use a verified author name when supplied. Project type and year are sufficient metadata for this edition.

The reusable stylesheet is [editorial.css](../assets/editorial.css). Copy the tokens and components needed for a future study. A retail or customer study can use its own findings and figures with the same reading rhythm.

| Element | Implemented treatment |
|---|---|
| Paper and ink | Warm paper #fbfaf7, charcoal #232820, secondary #50584f, rule #c7cbc1 |
| Accent | Forest #315a47 for links, focus and the discipline label |
| Display | Local Georgia/Iowan Old Style serif. Responsive headline 42–72 px, section heading 30–43 px, subheading 25 px |
| Reading | System sans, 18 px desktop and 17 px mobile, 1.7 line height. Graded monospace stack for equations. |
| Measure | Paragraphs up to 710 px. Wide evidence up to 960 px. Fluid gutters 20–64 px. |
| Rhythm | 8, 16, 24, 40 and 64 px spacing tokens. Sections use whitespace. Thin rules mark navigation, tables and captions. |
| Navigation | Compact masthead, native expandable contents, skip link and quiet dashboard link |
| Figures | A full-width original plot, a numbered caption with date, units and analytical basis, and nearby interpretation |
| Tables | Text aligned left and comparable numbers right, thin row rules, focusable overflow region for small screens |
| References | APA-style author/date entries with hanging indents and descriptive links. Local project evidence attached at the point of use. |
| Footer | Edition metadata and return link. No invented professional title, identity or affiliation. |

Use the article's .mast, .category, .deck, .meta, .contents, .wide, .table-wrap, .formula, figure/figcaption, .source and .references components. Keep full prose in the reading column. Preserve a figure's published units and sign convention when applying the style system.
